Def Jam: Fight for NY - PC port
===============================

This is a fan-made, non-commercial port of the GameCube game. It contains no game data:
the game is built on this PC from your own copy of the disc, right after installation.

What you need
-------------
- A disc image of Def Jam: Fight for NY for GameCube, USA release (disc id GNWE69), as a
  plain .iso file. Images in other formats (.rvz, .gcz, .nkit) can be converted with
  Dolphin: right-click the game > Convert File..., format ISO, no compression.
  Tip: put the .iso next to this installer (or in a folder next to it) and it is found
  automatically.
- About 6 GB of free disk space while building (about 2 GB once done).
- A 64-bit Windows 10 or 11 PC and a graphics card with Vulkan or Direct3D 11.

What happens
------------
1. The files are installed in the folder you choose (no administrator rights needed).
2. A console window opens and builds the game from your disc. This takes several minutes
   (about 8 on a 6-core PC) and uses all CPU cores; the window closes by itself when done.
3. Start the game from the Start menu, the desktop shortcut (both optional) or DefJam.exe
   in the game folder. The first start prepares
   the graphics shaders for about a minute; later starts are quick. The game opens
   fullscreen: Alt+Enter switches to a window, Esc opens the settings menu.
4. Optional: "Optimize for this PC" in the game folder (or "Def Jam - Optimize for this PC"
   in the Start menu) makes the game run faster (about 20 minutes). A game window opens
   and plays fights on its own while it measures; your saves and settings are not touched.
5. Optional: "Build PS2 HD textures" in the game folder (or the Start menu) copies the
   sharper textures of the PlayStation 2 version from your own PS2 disc image (.iso) into
   a mod, in a minute or two.

Updating
--------
Run the installer of the new version and pick the same folder. The disc is not needed again
(leave the disc field empty), and saves, settings and the optimization are kept. When the
game's code did not change, the build step finishes in seconds.

Controllers
-----------
Any gamepad works. Esc > CONTROLS > Layout picks how it plays: like the PlayStation 2, Xbox
or GameCube release. On Auto (the default) it follows the pad you use - a DualSense plays
like the PlayStation 2 release, an Xbox pad like the Xbox one. Menus use the game's own
buttons: the kick button goes back.
The keyboard plays too: W A S D move, I punch, J kick, K grapple, L run, E block, Q strong
attack, Tab target, arrow keys taunt, Enter pause. The button icons in the game show the
pad or the keys you are using, and switch as soon as you change; Esc > CONTROLS > Button
icons can keep one style (PlayStation, Xbox, Switch, GameCube, keyboard) or turn them off.

Playing online
--------------
Esc > System > Netplay. One player picks HOST ONLINE and Start Netplay; the game restarts
into a lobby that shows a host code (8 characters, with a Copy button) - send it to the
others. They pick JOIN ONLINE, press Space on Host Code to paste it (or enter it digit by
digit), then Start Netplay. The host clicks Start game once everyone is in. Both players
need the same disc (USA) and the same version of this port.
Windows Firewall asks once whether the game may use the network: allow it (private
networks are enough), above all on the PC that hosts. The players are introduced through
Dolphin's public netplay server (stun.dolphin-emu.org), with thanks to the Dolphin team;
the match itself runs directly between the PCs.

Mods
----
Put each mod in its own folder in userdata\Load\Mods\ (a .zip, .rar or .7z can be dropped
there as it is) and switch it on in Esc > MODS. Mods can replace textures and game files;
the game's own files are never changed. How to make one: modding\README.md. Online, both
players need the same mods that replace game files.

Everything the game writes (saves, settings, shader cache) stays in the install folder.
Uninstalling removes the game and asks whether to keep your saves and settings.
